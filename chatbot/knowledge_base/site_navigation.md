# Portfolio Website Navigation Guide

This page explains what each section of Marco Di Laudo's portfolio website contains and how to navigate to it.

## Home Page — /

The home page features:
- A hero section with Marco's name, title, and a brief value proposition
- Three featured projects from his portfolio
- A quick-view of his AI tools and tech stack
- A call-to-action to open the AI chatbot

## About Page — /about/

The About page contains:
- Marco's full professional biography
- Education history (Baylor University MBA/MSIS)
- Career timeline and work experience
- Personal interests and quick facts
- Links to LinkedIn, GitHub, and email contact

## Projects Page — /projects/

The Projects page shows all six portfolio projects in a filterable grid. Visitors can filter by category:
- All Projects
- Chatbot
- Agent Workflow
- LangChain Agent
- AI Media
- Machine Learning
- Web Application

Each project card shows the title, category, one-sentence summary, and tools used. Clicking "View Details" opens the full project detail page.

## Project Detail Pages — /projects/<slug>/

Each project has a dedicated page with:
1. Project title and one-sentence summary
2. Business problem the project solves
3. Tools and technologies used (shown as chips)
4. Key features (bulleted list)
5. Marco's specific role and contribution
6. The biggest technical challenge faced
7. Key learnings from the project
8. Screenshot or visual (where available)
9. Links to GitHub repository and live demo

## Skills Page — /skills/

The Skills page shows Marco's capabilities organized by category:
- Languages & Frameworks (Python, Django, SQL, JavaScript)
- AI / ML Tools (LangChain, scikit-learn, FAISS, OpenAI, n8n)
- Data & Analytics (Tableau, Excel, pandas)
- Cloud & DevOps (Render, GitHub, PostgreSQL)
- Business & Finance (Financial modeling, Bloomberg, valuation)

Each skill has an animated progress bar showing proficiency level.

## Resume Page — /resume/

The Resume page includes:
- An embedded PDF viewer showing Marco's full resume
- A download button for the PDF
- Summary highlights (education, experience, core skills)

## Contact Page — /contact/

The Contact page has:
- A contact form (name, email, subject, message)
- Direct links: email, LinkedIn, GitHub
- A prompt to use the AI chatbot for quick questions

## Chat Page — /chat/

The Chat page is a full-screen interface for the RAG-powered AI assistant. Visitors can ask anything about Marco's background, projects, skills, or how to navigate the site. The same chatbot is also available as a floating bubble (bottom-right corner) on every page of the site.

## Admin Panel — /admin/

Django admin panel for site management. Only accessible to Marco (superuser login required). Used to manage projects, skills, contact messages, and chat history.
