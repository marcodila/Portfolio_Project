# Portfolio Projects Overview

Marco's portfolio contains six AI/ML and web development projects completed during his graduate studies.

## 1. RAG Portfolio Chatbot (This project)

A production-ready Retrieval-Augmented Generation chatbot embedded directly in this Django portfolio website. Built with LangChain, FAISS, and OpenAI's GPT-4o-mini. The chatbot answers natural-language questions about Marco's background, projects, and skills. It uses a FAISS vector index built from five Markdown knowledge base files. Available at /chat/ and as a floating widget on every page of the site.

Key technologies: Python, Django, LangChain, FAISS, OpenAI API, JavaScript, Bootstrap 5.

## 2. n8n Automated Agent Workflow

An automation workflow built using n8n's visual workflow builder that chains AI tools, REST APIs, and data sources to execute a multi-step business process end-to-end without manual intervention. Demonstrates how no-code/low-code tools can orchestrate AI capabilities for real business automation use cases.

Key technologies: n8n, Google AI Studio, OpenAI API, Webhooks, REST APIs.

## 3. LangChain Conversational Agent

A tool-augmented LangChain agent that can reason over multiple data sources and take actions — going beyond simple chat to complete multi-step tasks autonomously. Uses the ReAct (Reason + Act) agent loop pattern with custom tool definitions.

Key technologies: Python, LangChain, OpenAI GPT-4o-mini, Pydantic, FAISS.

## 4. Google AI Studio Media Generation

An AI-powered content generation pipeline built with Google AI Studio and the Gemini Pro model. Produces structured media assets from minimal input prompts, demonstrating prompt engineering and multi-turn conversation strategies for content workflows.

Key technologies: Google AI Studio, Gemini Pro, Python, Google Generative AI SDK.

## 5. Machine Learning with scikit-learn

A complete supervised machine learning pipeline — from exploratory data analysis through model deployment — built with scikit-learn. Covers feature engineering, model selection (Logistic Regression, Random Forest, Gradient Boosting), cross-validation, and evaluation.

Key technologies: Python, scikit-learn, pandas, NumPy, Matplotlib, Jupyter Notebook.

## 6. Campus SkillSwap — Django Web App

A full-stack Django web application that connects university students to exchange skills peer-to-peer. Features include user authentication, skill listing CRUD, search and filter, a match system, and in-app messaging.

Key technologies: Python, Django, SQLite/PostgreSQL, Bootstrap 5, JavaScript.
